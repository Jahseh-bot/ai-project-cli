# 项目范围与待决问题

## 已确认

- 产品提供 CLI，用于创建项目，并支持技术选型及主流 Skills 的选择和适配。
- 同时覆盖 AI 辅助开发的通用应用和 AI 应用（用户选择 C）。
- 每个受支持的项目组合都必须符合成熟的工程化架构和目录结构要求。
- 目录名称和具体技术清单尚未确定；工程化要求需要转化为可验证的验收标准。
- 所有组合必须具备基础质量保障体系，包括 Lint；不能仅生成目录而缺少实际质量检查。
- 首版同时支持新建项目、检查已有项目及自动改造已有项目（用户选择 C）。
- 完成后用户需要通过 `npx` 一键启动 CLI；发布包名称、分发账号和发布安排尚未确定。
- 已有项目改造采用预览后应用：先分析并展示差异，保留自定义内容，用户确认后修改，提供本次改动的备份与恢复（用户选择 A）。
- 首版应用形态覆盖 Web、服务端、移动端和桌面端（用户选择 C），同时包含通用应用及 AI 应用。
- 扩展方式采用内置验证组合加扩展包（用户选择 B）。扩展包声明兼容条件、生成方式、已有项目改造方式及验证命令；只有通过验证的组合才标记为受支持。
- Skills 选择和适配仅面向开发时的 AI 编程助手（用户选择 A），不包含生成产品的运行时 Agent 技能管理；这不改变 AI 应用模板的范围。
- 编程助手覆盖目标为市面上所有主流工具，不限于 Codex、Claude Code 和 Cursor。具体清单随生态变化维护，各工具能力必须核实，不假定规则与 Skills 完全等价。
- Skills 来源采用精选目录加自定义来源（用户选择 B）：默认按技术栈推荐，并允许添加 Git 仓库或本地 Skills，记录来源与固定版本。
- Skills 仅安装到项目内，由各项目独立管理（用户选择 A）；CLI 不提供用户级全局 Skills 安装。
- CLI 本身不调用大模型（用户选择 A）：使用选择向导、兼容规则、版本化模板及确定性的检测与转换逻辑，无需模型 API Key。生成的 AI 应用可以有自己的模型服务配置。

## 建议默认值（待细化）

- 基础质量保障建议包含格式化、Lint、适用的类型或静态检查、单元测试、关键集成测试、构建与启动检查、CI、依赖锁定、配置校验和密钥泄漏检查。
- 包含 AI 功能的组合额外提供输出校验、基础效果评测及超时和失败处理测试。
- 受支持组合需要通过生成、安装、检查、测试与构建验证；具体验证环境和支持级别待定。

## 待决

- 已有项目改造的具体合并机制、无法合并的冲突处理、备份与回滚边界，以及无人值守模式。
- 首版技术栈、应用类型、AI 能力及开发工具适配范围。
- 主流编程助手的具体适配清单、版本范围，以及规则、技能和工具能力映射；区分覆盖目标与已验证支持。
- 生成项目的构建、运行、测试、评测、部署和规则维护验收标准。
- Skills 的筛选、许可、版本固定实现、本地来源快照、冲突处理及更新策略。
- 技术选型菜单的粒度：按应用形态提供单一推荐方案，或支持多个经过验证的框架选项。

## 工作目录

暂用 `ai-project-cli` 作为工作目录名称；产品名称未定。

## 执行阶段默认决策

用户已授权后续采用推荐方案，不再逐项提问。CLI 以 Node.js 分发，使用 Clack 提供选项式终端向导；基础模板包含 React/Vue、Node/FastAPI、Expo、Electron。使用兼容矩阵拒绝未实现组合；生成、静态检查、真实构建和原生运行验证分开报告。

## 当前实现边界

- 13 种基础模板，289 种允许生成的参数组合；组合文件结构经过自动测试，真实运行检查见 verification.md。
- 12 个内置开发 Skills 与 30 个固定版本的第三方 Skills 目录项；79 个助手项目级目录映射，尚未逐客户端认证。
- 改造器当前内置 npm/package.json 基础质量改造；保留冲突，支持前置内容校验和备份恢复。其他语言的完整自动改造仍需专用适配器。
- 支持本地声明式扩展叠加新项目文件，并通过 migrationFiles 接入已有项目的预览和应用流程；独立远端扩展注册表尚未实现。
- 需要 npm 登录及 scope 发布权限才能公开发布；当前工作环境未登录。

上述边界是已实现能力的说明，不是对用户原定范围的缩减；未覆盖的范围仍是待完成项。

## 0.2 交互与方案扩展

技术配置使用单选和多选控件，提供场景提示、推荐项、配置摘要及返回重选；名称和路径保留必要的输入或目录选择。增加 Next.js、Nuxt、Astro、Express、Fastify、SQLite，以及可复用业务/AI 包的 npm workspaces 架构。Skills 按内置保障、技术栈推荐和其他专项能力分组。
