# CLI 架构

- `bin/ai-project.js`：npm 可执行入口，负责顶层错误处理。
- `src/cli.js`：参数、交互向导、预览与确认。
- `src/templates.js`：确定性模板和兼容规则，输出相对路径到内容的映射。
- `src/files.js`：路径边界、符号链接拒绝、快照与原子文件替换。
- `src/transactions.js`：预览计划、前置内容校验、事务锁、备份和恢复。
- `src/skills.js`：精选开发技能、Git/本地来源快照、项目级适配、内容锁定。
- `src/extensions.js`：声明式扩展验证，加载前检查兼容范围，不执行扩展代码。
- `src/inspect.js`：只读能力清点，明确区分“存在配置”和“执行通过”。

## 事务边界

改造前先保存每个目标文件的原文与哈希。应用前验证所有文件和冲突，再逐文件写入并保存事务日志。不是多文件原子事务：进程中断时可用备份恢复；恢复前检查目标是否仍为原文或生成内容，避免覆盖后续人工编辑。应用和恢复使用排他锁；意外终止留下锁时应先确认没有运行中的 CLI，再移除 `.ai-project/transaction.lock`。

## 外部内容边界

技能导入是文本复制，不执行其中脚本。Git HTTPS 来源解析到 commit；本地来源解析到内容哈希。只支持 UTF-8 文本资源，拒绝符号链接和目录越界。私有源可以使用已有 Git 凭据机制，URL 中禁止嵌入凭据。

## 扩展边界

扩展包声明文件、兼容范围、覆盖清单和验证命令。显式指定扩展允许它提供构建脚本，因此安装依赖或运行检查前仍应审查文件。CLI 不自动执行扩展 `checks`，也不把声明的验证命令当成已验证证据。

## 选项式向导

`src/wizard.js` 使用 Clack 管理交互与取消，`src/frameworks.js` 提供框架适配，`src/architecture.js` 负责工作区转换，`src/sqlite-files.js` 提供 SQLite 适配。配置确认前不创建项目文件；命令行参数模式继续适用于 CI。
